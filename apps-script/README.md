# 신청서 → 구글 시트 연결 방법

1. 구글 드라이브에서 새 구글 시트를 만듭니다. (예: `어바웃 프리덤 코칭 신청`)
2. 시트 메뉴 [확장 프로그램 > Apps Script]를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 오른쪽 위 [배포 > 새 배포]를 누르고 유형을 [웹 앱]으로 고릅니다.
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
5. [배포]를 누르고 권한을 허용합니다. (시트 쓰기, 메일 보내기)
6. 나오는 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사해 `app.js`의 `ENDPOINT`에 넣습니다.

시트의 '진행 상태' 열은 신규 → 연락함 → 통화 완료 → 결제 완료처럼 직접 바꿔가며 쓰면 됩니다.
